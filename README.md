# 轻拍

一个使用 Expo / React Native 构建的手机照片压缩原型，面向 Android 和 iOS。拍摄或选择照片后在设备上压缩，显示原文件及结果的大小，用户可将压缩照片保存到系统相册，或通过系统分享菜单分享。

## 运行

需要 Node.js、npm 和手机上的 Expo Go：

```sh
npm install
npx expo start
```

手机与电脑连接同一网络，使用 Expo Go 扫描终端中的二维码。iPhone 可使用系统相机扫描二维码。拍照和系统相册保存需要在真实设备上测试，并授予相应权限。

## 使用说明

1. 选择 JPEG / WebP 和压缩程度，点击「拍照并压缩」或从相册选择。
2. 查看结果的体积，再选择保存到相册或分享。WebP 也可以在分享菜单中保存到文件。
3. 设置更改只应用于下一张照片。压缩结果临时存放在应用缓存中，未保存的结果可能被系统清理。

原照片不会被删除。拍摄时的临时原图不会自动保存。压缩是有损的，照片大小不保证一定变小；转换可能不保留原始元数据（包括位置信息），动态照片和动画仅处理静态图。系统相册对 WebP 的支持因设备而异，WebP 保存到相册失败时可以通过分享菜单保存到文件。此原型未实现批量处理、后台处理或删除原图。

## Web 版

在项目目录运行 `npm install` 后，执行 `npm run web`，在浏览器中打开终端显示的地址。也可以运行 `npx expo export --platform web` 生成可部署的静态文件到 `dist/`。

选择或拖入一张图片，设置格式和压缩程度，点击「压缩照片」后可预览并下载结果。图片只在浏览器中处理，不会上传；JPEG 会将透明区域填充为白色。浏览器对图片格式和大尺寸图片的支持可能不同，转换可能不保留元数据，动画仅处理静态画面。
